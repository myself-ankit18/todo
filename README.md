# 📝 Todo List Application

A professional, feature-rich To-Do List application built with **React**, **Vite**, and **Tailwind CSS**. This project demonstrates modern front-end development practices, interactive UI, and persistent data management.

## 🚀 Key Features

- **✅ CRUD Operations**: Add, complete, and delete tasks seamlessly.
- **💾 LocalStorage Persistence**: Your tasks are saved locally, so they persist even after a page refresh.
- **☁️ Real-time Clock**: A dynamic date and time display at the top of the application.
- **🧹 Clear All**: Quickly remove all tasks from the list with a single click.
- **⚡ Fast Feedback**: Instant UI updates and validation to prevent empty tasks or duplicates.
- **📐 Responsive Design**: Fully responsive layout using Tailwind CSS, optimized for all devices.

## 🛠️ Technology Stack

- **Framework**: [React](https://reactjs.org/) (Hooks: `useState`, `useEffect`)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [React Icons](https://react-icons.github.io/react-icons/)
- **Storage**: Browser LocalStorage

## 📦 Installation

To get started with the project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd todolist
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to `http://localhost:5173` to view the application.

## 📂 Project Structure

- `src/todo/todo.jsx`: Core application logic and state management.
- `src/todo/form.jsx`: Input form component for adding new tasks.
- `src/todo/list.jsx`: Individual task item component with actions.
- `src/todo/todo.css`: Custom CSS for fine-tuned styling.
